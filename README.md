# MAHJONG ANALYST

自分で考えて打ち、打牌のあとに AI の答え合わせを受ける、個人用の麻雀トレーニングアプリ（四人打ち・日本式リーチ麻雀、Mac / iPhone 向け PWA）。

基準文書：[docs/SPEC.md](docs/SPEC.md)

## 起動

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。iPhone で試すときは、同じネットワークから `npm run dev -- --host` で表示されたアドレスを開く。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド（型チェック込み・Service Worker 生成） |
| `npx vite preview` | 本番ビルドの確認（オフライン動作の確認用） |
| `npm test` | テスト一式 |
| `npm run bench` | シャンテン数・牌効率の速度計測 |
| `npm run league -- 40` | AI同士のリーグ戦（打ち筋と強さの比較） |
| `npm run eval-demo` | 打牌評価の例 |
| `npm run eval-timing` | 打牌評価の処理時間 |
| `npm run calibrate` | AI 同士の大量対局で評価の定数を実測（`GAMES=1000` で 8,000 半荘） |
| `npm run validate -- 40` | 評価の予測と実際の結果の比較 |
| `npx tsx bench/verify-flags.ts <JSON>` | アプリで書き出した「要検証」の判断を詳しく再評価 |
| `npm run golden:shanten` / `npm run golden:score` | 正解データの再生成（Python `mahjong` を使用、要 uv） |

## 対局画面の操作

- **Mac**：牌をクリックで打牌。←→ で牌を選び Enter で打牌、Esc で立直の取り消し／鳴きのスキップ。評価パネルは右側。
- **iPhone**：横画面で打つ（雀魂のスマートフォン版と同じ配置：卓を中央に大きく、手牌を画面の下いっぱいに、ポン・立直などのボタンを手牌の右上に、局の情報とドラを左上に、速さ・終了とAI評価を右上に置く）。開いた時から横画面：縦持ちのときは画面ごと90度回して表示するので、画面の向きのロック中でも端末を左に倒して持てば横画面で使える（`src/viewport.ts`）。タイトル・弱点分析・振り返りも横画面に合わせて詰めて並べる。牌を1回タップで選択、もう一度タップで打牌。AI評価は右上のカードをタップして開く（開いても手牌は隠れない。自分の番になると自動で閉じる）。
- **AIの打牌の速さ**：速い・普通・遅め の3段階。タイトルの設定のほか、対局中も上の「速さ」ボタンで切り替えられる（待ち時間は 打牌 0.12秒／0.55秒／1.2秒）。
- 立直・カン・九種九牌は確認してから実行。
- 立直した後は、ツモ切りしか選べないときは自動で切る（ツモ和了・カンを選べるとき、ロンできるときだけボタンが出て自分で選ぶ）。選択肢のない自動の打牌は評価しない。
- **打牌音・発声**：打牌のたびに牌の音、リーチ・ポン・チー・カン・ロン・ツモは声で知らせる（端末の日本語音声で読み上げ、席ごとに声の高さを変える。音源ファイルは使わない）。タイトルの設定と、対局中の 🔊 ボタンで「効果音＋発声／効果音だけ／なし」を切り替える。iPhone はマナーモード（消音スイッチ）だと鳴らないことがある。
- 打牌・ポン・チー・カン・スキップ・ロン・ツモ・九種九牌のどれを選んでも、その直前の局面で選べた全ての行動を比較した評価（100点満点・判断損失・良かった点／改善点）が表示される。立直できる場面では「立直／ダマ」の比較も出る。最善の選択とあなたの選択の**局収支の見込み**（この局の終わりまでの点数の増減の期待値。和了・放銃・聴牌料・立直棒を含む）も表示する。詳細・専門分析はタブで切り替え。
- 対局終了時に、打牌評価の振り返り（平均点・判断損失の合計・評価の低かった打牌）を表示。
- 対局と評価は自動で保存される。アプリを閉じてもタイトルの「続きから」で再開でき、「対局履歴・振り返り」で過去の判断を局面つきで見直せる。振り返りでは、最善を選んだ場合とあなたが選んだ場合の切った後の牌姿（鳴きは鳴いた面子つき）を並べ、それぞれの向聴数・受け入れ枚数・有効牌も表示する。
- 和了した局の終わりには、点数を見せる前に点数計算テストが出る（設定でオフにできる）。親・子、ロン・ツモに合わせた点数表（符×翻のマスと、満貫〜二倍役満の欄）が出るので、その和了の点数のマスを選ぶ。正答率は弱点分析に表示される。
- 画面は雀魂の画面構成を参考にしている（中央の局情報パネルに各家の風と点数、手番の家が光る、卓上の立直棒、四隅のプレイヤー表示、大きな丸い操作ボタン、演出のある結果画面）。雀魂のロゴ・キャラクター・画像素材は使っていない。
- **要検証の印**：振り返り・復習問題で評価に納得できない判断に「⚑ 要検証」をつけ（理由・メモつき）、弱点分析の画面でまとめて再評価・JSON で書き出しができる。一覧の項目を押すと、その局面（切った後の牌姿つき）と評価の中身を開いて確かめられる（[coach.md](docs/coach.md)）。
- 「弱点分析・復習問題」：判断を 8 つの分類に分け、5 つの能力値を直近 10 半荘・30 半荘・累計で表示。70 点未満だった判断は復習問題になり、間隔を空けて再出題される。苦手な分類だけの重点練習もできる。
