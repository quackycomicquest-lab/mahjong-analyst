# 要検証の判断の再評価（評価エンジン v0.3.1 → v0.4.0）

実際の対局で「⚑ 要検証」の印をつけた **36 判断**（2026-11-07 書き出し）を、試行回数を増やして再評価し、評価が変わったものの原因を調べて直した。
書き出した JSON はリポジトリに入れていない（個人の対局データのため）。調べ方は `npx tsx bench/verify-flags.ts <JSON> [試行回数]`。

## 方法

- 元の評価は全て iPhone の軽量評価（1候補 100 試行）。これを 1候補 2,000 試行 × 乱数 3 通りで評価し直し、「元の点数とのずれ」「乱数による点数のばらつき」「最善手の入れ替わり」を見た。
- 点数が変わった判断を 1 つずつ局面（手牌・4人の河・副露・ドラ）まで見て、原因を「試行回数が少ないことによるぶれ」と「評価方法の問題」に分けた。前者は評価の仕組みで減らし、後者は直した。

## 見つかった問題と修正

### 1. 軽量評価の点数が試行のぶれで大きく動く（修正）

36 判断のうち 10 判断ほどは、試行を増やすと点数が 20〜50 点動いた（例：序盤の字牌切り 72点 → 100点、4索切り 53点 → 94〜100点）。候補どうしの期待値差が数十点しかない局面で、100 試行の誤差（±300点前後）が差として表れていた。

修正：全候補を同じ回数だけ試したあと、**期待値の上位 4 候補と選んだ候補に 2 倍の試行を足して比べ直す**。最善手と評価点を決めるのはこれらの差なので、計算を 1.8 倍に抑えたまま誤差を減らせる。

同じ局面を軽量評価で乱数を変えて 5 回評価したときの、評価点の最大と最小の差（36 判断の平均）：**25.2点 → 11.6点**。高精度の評価（3,000 試行）とのずれの平均：11.7点 → 6.5点。

### 2. 役のない仕掛けを高く評価していた（修正）

役牌でない南のポン、ポン・チーして役のない聴牌（形式聴牌）に取る判断が、和了率 0% なのに「鳴かない」より高い評価になっていた（3 判断。鳴かなかった判断が 46〜82点）。
流局時の聴牌料（実測 +1,092点、ノーテンは −1,684点）を、山が 40 枚以上残っている局面でも満額見込んでいたため。実際には、役のない手は他家の立直が出たら降りるので、聴牌のまま流局できることは少ない。

修正：評価する時点で既に仕掛けている手（この候補のポン・チーを含む）が聴牌しても役がなければ和了できないものとし、脅威が見えたら降りる。流局時の聴牌料は「他家の立直が出なかった割合」だけ見込む。立直が出る割合は AI 同士 2,000 半荘で実測した（[calibration.md](calibration.md)）。3 判断とも鳴かないのが最善・100点になった。

### 3. 立直者に対して1向聴のまま押し続けていた（修正）

脅威（立直・2副露以上）があるとき、シミュレーション内の自分は 2向聴以上なら降りるが、**1向聴なら危険な牌でもツモ切りで押していた**。そのため、1向聴を保つ打牌（例：完全な安全牌の字牌を切る）は「この後も押し続けて放銃する」と見積もられ、向聴数を落とす打牌が高く出ていた。
また、危険度を評価した時点のまま使っていたため、時間がたっても安全な牌が増えず、降りても局の終わりまでの放銃率が 40% 近くになっていた。

修正：
- 1向聴なら、向聴数を保てる牌のうち最も安全なものを切る（回し打ち）。その放銃率が 5% を超えるなら降りる。立直が 2 人以上なら 1% を超えると降り、聴牌に取るために危険な牌も切らない。
- シミュレーション中に誰かが切って通った牌は、立直者に対しては以後現物にする。
- 降りたときの局全体の放銃率は、例えば立直 1 人・山 54 枚の局面で 41% → 16% になった。

### 4. 4枚目の字牌を安全牌と見ていなかった（修正）

最後の 1 枚の字牌（他の 3 枚が河・副露・ドラ表示牌に見えている）は国士無双以外で当たらないが、「3 枚見えている字牌」と同じ危険度にしていた。
立直 2 人に対して 4 枚目の白・中を切った判断が 59〜61点だった。

修正：4 枚とも見えている字牌は現物と同じ扱い。この 2 判断は 100点になった。

## 直さなかったもの

- **対々和・ドラ3のポン**（2索のポンをスキップ、元 69点 → 再評価 50点前後）：ポンすると対々和が見え、ドラ 3 で満貫以上。鳴いた方が和了率が 4% → 17% と大きく上がる。評価の通りと判断した。
- **立直 2 人・山 11 枚でのチー**（スキップ 24点）：山が残り少なく、チーで聴牌に近づけば聴牌料を取れる見込みが大きい。評価の通りと判断した。
- **押し引きに打点を使っていない**：満貫以上の手なら 1向聴でも押す、といった判断は入れていない（[evaluator.md](evaluator.md) の「分かっている限界」）。

## 結果（36 判断）

| | v0.3.1（アプリでの評価） | v0.4.0（軽量評価、乱数 5 通りの平均） |
|---|---|---|
| 鳴かない判断が 100点になった役なし仕掛け | 0 / 3 | 3 / 3 |
| 4枚目の字牌を切った判断 | 59・61点 | 100・100点 |
| 立直 2 人に完全な安全牌（南）を切った判断 | 42点 | 82点 |
| 評価点のばらつき（最大−最小、平均） | 25.2点 | 11.6点 |

何切る問題との照合（[nnkr-comparison.md](nnkr-comparison.md) と同じ 135 問・乱数 2 通り）：多数派と最善手の一致 81／83 → 83／82、多数派 50% 以上の 71 問で一致 50／49 → 55／53。
多数派の答えが 70点未満の問題は 13／18 → 20／19 に増えた。調べると、どれも誤差が小さくなって減点の差し引きが減ったためで、意見の割れている問題（多数派 50% 未満）がほとんど。

処理時間は full で中央値 205ms → 372ms、light で 56ms → 100ms（Web Worker で動くので対局は止まらない）。
