# 定石・統計との照合（評価エンジン v0.5.0）

強い打ち手の牌譜（天鳳など）は利用条件により評価エンジンの改善に使えないため、
麻雀の統計研究・戦術書で広く知られている結論を、**自作の局面**に置き直して照合する。
局面と期待する判断は `bench/strategy-cases.ts`、実行は `npx tsx bench/strategy-check.ts [試行回数] [乱数...]`。

- 期待する判断は「必ずこれが最善」と言えるものだけを最善手として確かめ、評価が割れうるものは「大きな減点にしない（下限点）」で確かめる。
- 文章や問題をそのまま写さず、数字・判断の基準だけを自分の言葉でまとめている。
- 乱数 2 通り（1・7）で評価し、両方で満たせば合格。

## 照合する定石（11 件）

| ID | 分類 | 定石 |
|---|---|---|
| R1 | 立直判断 | 先制・役なしの嵌張聴牌は立直する |
| R2 | 立直判断 | 先制・断幺九平和の安い両面聴牌も立直する |
| R3 | 立直判断 | 他家の先制立直に、現物を切って両面聴牌なら追いかけ立直 |
| P1 | 押し引き | 先制立直に対して、両面聴牌なら無スジでも押す |
| P2 | 押し引き | 先制立直に対して、打点のない1向聴は現物で降りる |
| P3 | 押し引き | 先制立直に対して、2向聴以上は現物で降りる |
| P4 | 押し引き | 先制立直に対して、満貫以上が見える序盤の1向聴は押す |
| S1 | 安全牌 | 降りるときは現物。中張牌の無スジ（5）は大きく減点 |
| C1 | 鳴き | 序盤の役牌の対子は1枚目からポン |
| C2 | 鳴き | 終盤、役のある1向聴はチーで聴牌に取る |
| E1 | 牌効率 | 序盤、孤立したドラは孤立した端牌より残す |

## 見つかった問題と修正

### 他家のツモの支払いを収支に入れていなかった（修正、v0.5.0）

v0.4.1 では P1（両面聴牌の押し）だけが合わず、現物を切って聴牌を崩す降りを最善としていた（押しの評価 53〜56点）。

シミュレーションでは「他家の和了で局が終わる確率」は掛けていたが、そのときの自分の失点を 0 としていた。
他家どうしのロンなら 0 だが、ツモなら支払う。降りて局が長引くほど他家のツモで払う見込みが増えるのに、それを数えていなかったため、
**降りの収支が良く見えすぎていた**（以前から「分かっている限界」に書いていた問題）。

修正：他家の和了で局が終わったときの平均失点を AI 同士 2,000 半荘で実測し（`bench/calibrate-otherwin.ts`、[calibration.md](calibration.md)）、
他家の和了で終わる確率に掛けて収支に入れる。P1 は押し（4萬切り立直）が最善になり、11 件すべて合格した。

### 局面の作り方の誤り（照合側を修正）

P4 は最初、押す牌を 7筒にしていたが、7筒を切ると嵌張が残り、4筒（両面が残る）より明らかに形が悪い。
エンジンは 4筒・赤5萬切りの押しを降りより高く評価していたので、照合の局面を 4筒切りに直した。

## 結果

| | v0.4.1 | v0.5.0 |
|---|---|---|
| 定石との照合（11 件） | 9 件（P1・P4 が不合格） | 11 件 |
| 何切る問題：多数派と最善手が一致（135 問、乱数 1／7） | 82／80 | 82／80 |
| 何切る問題：多数派の答えが 90点以上 | 102／98 | 103／99 |
| 要検証の 51 判断 | — | 大きく変わったのは押し引きの判断（例：立直2人への完全安全牌の南 79点 → 85点） |

AI 同士 40 半荘での当たり具合（`npm run validate -- 40`）：和了率・放銃率の予測は変わらない（和了率 予測 17.7% ／ 実際 22.9%）。
局の収支の予測は +120点 → −219点（実際 +169点）になった。他家のツモの支払いを入れた分だけ下がり、和了率をやや低く見積もっている分
（シミュレーション内の自分の打ち方が AI より和了しにくい）が表に出た。候補どうしの比較（評価点）はこの補正で定石に近づいたが、
局収支の見込みの絶対値は実際より 400点ほど低めに出る。
