# AI 同士の大量対局による評価の補正

評価エンジン（`src/engine/evaluator/`）と AI の守備判断（`src/engine/ai/danger.ts`）が使う定数を、
経験則の仮置きから **AI 同士の自己対局で実測した値** に置き換えた。

- 実測値：`src/engine/calibration/calibration.json`（読み込みは `calibration.ts`。サンプルが少ない項目は経験則の既定値に戻る）
- 再生成：`npm run calibrate`（8 並列。`GAMES=1000` で各 1,000 半荘＝計 8,000 半荘、Mac で約 6 分）
- 検証：`npm run validate -- 40`（`MAHJONG_NO_CALIBRATION=1` を付けると補正前の定数で測れる）

## 集計の方法

シミュレーションでは全員の手牌が分かるので、「その牌が実際に当たり牌だったか」を、捨てたかどうかに関係なく数えられる。
打つ人の視点で手牌の各牌を危険度の分類（現物・スジ・無スジ・字牌の見え枚数・壁など）に分け、脅威（立直・3副露・2副露）ごとに
「その牌でロンされるか（役あり・フリテンでない）」を記録した。隠し情報を使うのは集計のときだけで、評価・AI の実行時は使わない。

対局者：速攻型・守備型・打点型（強さ3）と速攻型（強さ2）。席は半荘ごとに入れ替え。

## 評価の当たり具合（`npm run validate -- 40`、席0の打牌を評価し、その局の実際の結果と比較）

| | 補正前 | 補正後 | 実際 |
|---|---|---|---|
| 和了率の予測 | 11.9% | 13.8% | 22.9% |
| 放銃率の予測 | 4.3% | **17.2%** | 17.2% |
| Brier スコア（和了） | 0.169 | 0.163 | — |

- 放銃率は、見えていない脅威への放銃を入れたことで実際と一致した。
- 和了率はまだ低めに出る。席0を「鳴かない牌効率ボット」にすると差は 4 ポイント（予測 12.1%／実際 16.3%）まで縮み、予測 30% 以上の帯ではほぼ一致する（37.8%／39.9%、61.0%／58.5%）。

### シミュレーションに鳴きを入れた後（席0：打点型AI、40半荘）

| | 鳴きなし | 鳴きあり | 実際 |
|---|---|---|---|
| 和了率の予測 | 13.8% | 15.1% | 22.9% |
| Brier スコア（和了） | 0.1625 | 0.1570 | — |
| 放銃率の予測 | 17.2% | 17.1% | 17.2% |

シミュレーション内の自分は、向聴数が進み役（役牌・断幺九・混一色）の見込みがあるときにポン・チーする（役牌のポン以外は鳴いた後が2向聴以内、チーは上家の捨て牌だけ、鳴く機会は実測した「欲しい牌が切られる割合」で間引く）。
差は縮んだが、序盤の遠い手（予測 2%／実際 10%）を中心に低めの予測が残る。

### シミュレーションの打ち方を賢くした後（各40半荘）

追加した打ち方：有効牌でなくてもツモ牌の方が手の中で最も孤立した牌より役立つなら入れ替える（形の改善）／聴牌に取るときは河にある牌を待ちにしない打牌を優先（フリテン回避）／対々和の見込みがあるポン。

| | 鳴き追加後 | 打ち方改善後 | 実際 |
|---|---|---|---|
| 和了率の予測（打点型AI） | 15.1% | 16.7% | 22.9% |
| Brier スコア（打点型AI） | 0.1570 | 0.1538 | — |
| 局の収支の予測（打点型AI） | −159点 | −19点 | +170点 |
| 和了率の予測（鳴かない牌効率ボット） | 12.9% | 14.3% | 16.3% |

鳴かない打ち手では予測帯ごとにほぼ一致する（21.5%／23.8%、37.4%／38.4%）。鳴く打ち手の残りの差（約6ポイント）は、AI の鳴き・立直判断がシミュレーションの方針より積極的なことによる。

### 打牌選びを受け入れ枚数で行うようにした後（v0.3.0、各40半荘）

シミュレーション内で向聴数が進んだときの打牌を、安全度だけでなく受け入れ枚数（聴牌なら待ちの残り枚数）で選ぶようにした。

| | 打ち方改善後 | v0.3.0 | 実際 |
|---|---|---|---|
| 和了率の予測（打点型AI） | 16.7% | 18.0% | 22.9% |
| Brier スコア（打点型AI） | 0.1538 | 0.1521 | — |
| 放銃率の予測（打点型AI） | 16.9% | 16.8% | 17.2% |
| 和了率の予測（鳴かない牌効率ボット） | 14.3% | 15.5% | 16.3% |

鳴かない打ち手では予測帯ごとにほぼ一致する（21.8%／21.2%、37.5%／38.9%）。

## 分かっている限界

- 向聴数が進むときの打牌は受け入れ枚数で選ぶが、向聴数が進まないときの形の改善は「周りに使える牌が何枚あるか」による簡易判定（速さのため）。聴牌後の待ちの選び直し（ダマでの良形変化）もしない。
- 鳴きの条件（役の見込み・2向聴以内）は積極的な打ち手より厳しめ。鳴く打ち手の和了率は低めに予測される（候補どうしの比較では差が相殺されやすいが、絶対値はずれる）。
- 安全牌は評価した時点のもので固定。時間とともに通る牌が増えることは入っていないため、降りるときの「安全牌を先に切る」価値が小さめに出る。
- 実測は AI 同士の対局なので、人間同士の対局とは傾向が異なる可能性がある。
