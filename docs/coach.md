# 弱点分析と復習問題（仕様 §7、§4-1 ④ Mahjong Coach）

コード：`src/engine/coach/`（`classify.ts` 分類、`abilities.ts` 集計、`review.ts` 出題間隔）、画面は `src/ui/AnalysisScreen.tsx`・`src/ui/ReviewScreen.tsx`。
タイトルの「弱点分析・復習問題」から開く。

## 判断の分類（仕様 §7-2）

保存した評価（判断直前の局面と評価結果）だけから、次の順に判定する。

| 分類 | 条件 |
|---|---|
| 鳴き判断 | ポン・チー・カン・スキップの判断 |
| その他 | 和了・暗槓・加槓・九種九牌（能力値には入れない） |
| オーラスの順位判断 | オーラス（延長戦を含む）の打牌 |
| リーチ判断 | 選んだ牌で立直とダマの両方を選べた打牌 |
| 押し引き | 他家の脅威（立直・2副露以上）があり、押すのが正しい局面 |
| ベタオリ | 降りるのが正しい局面で、安全な牌を選ばなかった打牌 |
| 安全牌選択 | 降りるのが正しい局面で、安全な牌の中から選んだ打牌 |
| 打点構築 | 脅威がなく、最善と同じ向聴数の候補の間で和了時の打点に3割以上の差がある打牌 |
| 牌効率 | 上のどれにも当たらない打牌 |

## 能力値（追加提案の 5 能力値）と期間（仕様 §7-1）

| 能力 | 含める分類 |
|---|---|
| 牌効率能力 | 牌効率 |
| 攻撃判断能力 | 打点構築・リーチ判断・鳴き判断 |
| 守備判断能力 | ベタオリ・安全牌選択 |
| 押し引き能力 | 押し引き |
| 順位戦略能力 | オーラスの順位判断（順位期待値は未対応のため、収支の期待値で評価） |

- 能力値 = 含める判断の平均評価点（100点満点）。5 判断未満は「データ不足」。
- AI との一致率は使わない（最善と違っても期待値がほぼ同じなら減点されない評価点を使う。仕様 §7-1）。
- 期間：直近 10 半荘・直近 30 半荘・累計（中断中の対局も 1 半荘として数える）。
- 重点課題：5 判断以上ある分類のうち、平均判断損失が最も大きいもの。

## 復習問題（仕様 §7-3）

- 70点未満だった判断は、弱点分析を開いたときに自動で復習問題に登録される（すぐ出題）。
- 出題：当時の局面（4人の河・副露・点数・ドラ・立直）をそのまま出し、打牌は牌を選んで、鳴き・和了はボタンで答える。iPhone では対局画面と同じく 2 回タップで確定。
- 答えはその場で評価し直し（保存した局面からの再評価、仕様 §3-4）、元の対局での自分の選択と並べて表示する。
- 次の出題日：

| 今回の点数 | 次の出題 |
|---|---|
| 90点以上 | 1日後 → 3日後 → 前回の2.5倍…（30日以上空いたら「身についた」として出題しない） |
| 70〜89点 | 前回の間隔の1.2倍（最低1日） |
| 70点未満 | 10分後にもう一度 |

- 「今日の復習」は期限が来た問題を古い順に最大 10 問。「重点練習」は期限に関係なく、その分類のまだ身についていない問題を、前回の点数が低い順に最大 10 問。
- 復習の状態は IndexedDB の `reviews` ストア（DB バージョン 2 で追加）に保存する。

## 分かっている限界

- 分類は評価結果からの自動判定で、1 つの判断は 1 つの分類にだけ入る（例：脅威がある局面の立直判断は「リーチ判断」になる）。
- 評価エンジンを改良すると、同じ局面でも点数が変わることがある。復習の再評価は、その時点のエンジンで行う。

## 点数計算テスト

コード：`src/engine/coach/scoreQuiz.ts`、画面は `src/ui/ResultModal.tsx`。

- 誰かが和了した局の終わりに、点数を見せる前に「この和了は何点？」を出す（タイトルの設定「和了時の点数計算テスト」でオン・オフ）。ダブロンは和了ごとに出題。
- 答え方：その和了に合った点数表（親・子 × ロン・ツモ）を出し、点数にあたるマスを選ぶ。
  - 符×翻のマス：20〜110符 × 1〜4翻（110符を超える和了のときは、その符まで行を足す）。満貫に達するマスは「満貫」と表示。ありえないマス（ロンの20符、1翻の25符、ツモの20符1翻・25符2翻）は選べない。
  - 満貫以上の欄：満貫・跳満・倍満・三倍満・役満・二倍役満（三倍以上の役満のときはその倍数まで足す）。
  - 判定は点数で行う。30符4翻と60符3翻のように同じ点数のマスはどちらも正解（そのときは実際の翻・符も示す）。
  - 答えた後は、正解の点数のマスを緑、選んだ誤りのマスを赤、実際の翻・符のマスを白枠で示す。
- 出題で見せるもの：和了形・副露・和了牌、ロン／ツモ（放銃者）、親か子か、場風・自風、ドラ表示（立直なら裏ドラ表示）、手牌からは分からない状況役（立直・一発・海底・河底・嶺上開花・槍槓・天和・地和）。
- 点数は本場・供託を含めない基本の支払い（ロン：放銃者の支払い、子のツモ：子の支払い-親の支払い、親のツモ：○オール）。
- 正解は点数計算エンジン（Python mahjong と 10,000 件で照合済み）の結果。点数表の計算も同じ 10,000 件で、実際の和了のマスが正解の点数になり、選べるマスであることを確認している。
- 答えると、正誤と役・翻・符・符の内訳を表示する。
- 結果は IndexedDB の `quizzes` ストア（DB バージョン 3 で追加）に保存し、弱点分析に正答率（満貫未満・満貫以上の内訳）を、対局終了画面にその対局の正解数を表示する。
